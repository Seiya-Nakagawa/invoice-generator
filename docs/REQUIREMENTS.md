# 要件定義書 — 請求書 PDF 化 & Gmail 下書き作成ツール

## 1. 概要

Google スプレッドシート上で作成した請求書を、ワンクリックで以下まで完了させる Google Apps Script (GAS) ツール。

1. アクティブシートを PDF として書き出し、スプレッドシートと同じ Google ドライブフォルダに保存する。
2. その PDF を添付した Gmail の下書きを作成する。

下書きの送信操作は利用者が Gmail 上で行う前提（誤送信防止のため自動送信はしない）。

## 2. 利用者・利用シーン

- 利用者: 請求書を月次でメール送付する個人事業主・業務担当者。
- 利用シーン: 月初〜月中に当月分または前月分の請求書スプレッドシートを開き、メニューから1クリックで PDF 化＋下書き作成まで済ませたい場面。

## 3. 機能要件

### 3.1 メニュー登録

1. スプレッドシートを開いた際に、独自メニュー「請求書処理」を表示する。
2. メニュー内の項目「PDF作成＆Gmail下書き」から処理を起動できる。

### 3.2 対象年月の自動決定

1. スクリプト実行時の日付に応じて、PDF ファイル名およびメール件名・本文に使う「年」「月」を自動的に決定する。
2. 実行日が当月 15 日以前なら「前月」、16 日以降なら「当月」を対象とする。

### 3.3 PDF 作成

1. アクティブシートのみを PDF としてエクスポートする。
2. 用紙サイズ A4・縦向き・幅フィット・上下左右余白 0.5 インチ・グリッドライン非表示・スプレッドシート名/シート名非表示・固定行/固定列の繰り返しなし、で出力する。
3. 出力した PDF を、スプレッドシートと同じ Google ドライブフォルダに保存する。
4. PDF のファイル名は設定値テンプレートに基づき、`{YEAR_MONTH}` を「YYYY年M月」形式の文字列に置換して決定する。

### 3.4 Gmail 下書き作成

1. 設定値の宛先・件名テンプレート・本文テンプレート・署名テンプレートに基づき下書きを作成する。
2. 件名・本文テンプレートの `{YEAR}` `{MONTH}` を対象年・月に置換する。
3. 作成した PDF を下書きに添付する。
4. 下書きは Gmail に保存されるのみで、自動送信はしない。

### 3.5 設定の差し替え

1. メール宛先・件名・本文・署名・PDF ファイル名・PDF エクスポートオプションは、コード上の設定ファイル（`mail_invoice/config.gs`）の定数を編集することで差し替え可能とする。

## 4. 非機能要件

- 実行環境: Google Apps Script ランタイム（コンテナバインド型でスプレッドシートに紐付く）。
- 外部依存: なし。標準サービス（Spreadsheet / Drive / Gmail / UrlFetch / Script）のみを利用する。
- 権限スコープ: `@OnlyCurrentDoc` により、スクリプトのアクセス対象を当該スプレッドシートに限定する。
- ログ・通知: 主要処理の進捗および異常を `Logger.log` に記録し、ユーザーに見せたいエラーは `SpreadsheetApp.getUi().alert` でダイアログ表示する。

## 5. 制約・前提

- スプレッドシートが Google ドライブ上のいずれかのフォルダ配下に置かれていること（マイドライブ直下や親フォルダなしの状態は対象外）。
- 利用者が Gmail / Drive / UrlFetch / Spreadsheet の OAuth スコープに同意済みであること。
- 請求書スプレッドシートのアクティブシートが、そのまま PDF 化したいシートになっていること（複数シート結合は行わない）。

## 6. スコープ外

- 下書きの自動送信。
- 複数シート（請求書＋明細など）を 1 つの PDF にまとめる処理。
- スプレッドシート UI 上での設定値編集（フォーム・サイドバー化）。
- 過去分・将来分など任意年月の指定実行（実行日基準のロジックのみ提供）。
