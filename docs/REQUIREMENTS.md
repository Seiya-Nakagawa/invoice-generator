# 要件定義書 — 請求書 PDF 化 & Gmail 下書き作成ツール

## 1. 概要

Google スプレッドシート上で作成した請求書を、テンプレートからのスプレッドシート作成から PDF 化、Gmail 下書き作成までを効率化する Google Apps Script (GAS) ツール。

1. **シートの自動作成**: 指定されたフォーマットシートをコピーして当月用のシート（YYYYMM形式）を作成する。
2. **手動更新**: 利用者が作成されたシートの内容を必要に応じて更新する。
3. **PDF 化 & 保存**: ボタン一つで、対象シートを PDF として書き出し、スプレッドシートと同じ Google ドライブフォルダに保存する。
4. **Gmail 下書き作成**: その PDF への共有リンクを記載した Gmail の下書きを作成する（添付はしない）。

下書きの送信操作は利用者が Gmail 上で行う前提（誤送信防止のため自動送信はしない）。

本ツールは**複数の取引先**へ請求書を送付する用途を前提とし、取引先ごとに別のスプレッドシート
（＝別のコンテナバインドスクリプト）で運用する。実装は全取引先で共通とし、取引先ごとの差分は
スクリプトプロパティで吸収する（3.5 節参照）。

## 2. 利用者・利用シーン

- 利用者: 請求書を月次でメール送付する個人事業主・業務担当者。
- 利用シーン: 月初〜月中に当月分または前月分の請求書スプレッドシートを開き、メニューから1クリックで PDF 化＋下書き作成まで済ませたい場面。

## 3. 機能要件

### 3.1 シートの作成

1. 指定されたフォーマットシート（`config.gs` で設定）をコピーし、当月用の新しいシートを作成する。
2. 新しいシートの名前は、「YYYYMM」形式（例：「202404」）とする。
3. 作成したシートに、請求日（当月末日）とお支払い期限（翌月末日）を書き込む。書き込み先のセルは
   取引先ごとに変更できる。
4. この処理は、メニューから手動実行、または月次の時間主導型トリガーによって実行される。

### 3.2 メニュー登録

1. スプレッドシートを開いた際に、独自メニュー「請求書処理」を表示する。
2. メニュー内の項目「当月シート作成」「PDF作成＆Gmail下書き」から処理を起動できる。

### 3.2 対象年月の自動決定

1. スクリプト実行時の日付に応じて、PDF ファイル名およびメール件名・本文に使う「年」「月」を自動的に決定する。
2. 「PDF作成＆Gmail下書き」は常に**実行日の前月**を対象とする。
3. 「当月シート作成」は**実行日の当月**のシートを作成する。

### 3.3 PDF 作成

1. 指定されたシート（YYYYMM形式の名前）を PDF としてエクスポートする。
2. 用紙サイズ A4・縦向き・幅フィット・上下左右余白 0.5 インチ・グリッドライン非表示・スプレッドシート名/シート名非表示・固定行/固定列の繰り返しなし、で出力する。
3. 出力した PDF を、スプレッドシートと同じ Google ドライブフォルダに保存する。
4. PDF のファイル名は設定値テンプレートに基づき、置換して決定する。
5. 同名の PDF が保存先フォルダに既に存在する場合は、既に配布済みの請求書リンクが変わることを
   避けるため、上書きせず処理をスキップする。

### 3.4 Gmail 下書き作成

1. 設定値の宛先・件名テンプレート・本文テンプレート・署名テンプレートに基づき下書きを作成する。
2. 件名・本文テンプレートの `{YEAR}` `{MONTH}` `{リンク}` を対象年・月・PDF共有リンクに置換する。
3. PDF は添付せず、共有リンクを本文に含める。
4. 下書きは Gmail に保存されるのみで、自動送信はしない。

### 3.5 取引先ごとの設定

1. 取引先ごとに異なる値は GAS のスクリプトプロパティで管理し、ソースコードは全取引先で共通とする。
2. スクリプトプロパティは以下のとおりとする。

    | キー | 必須 | 既定値 | 用途 |
    | ---- | ---- | ------ | ---- |
    | `EMAIL_SUBJECT_TEMPLATE` | 必須 | なし | メール件名・PDF ファイル名のテンプレート |
    | `EMAIL_TEMPLATE_LABEL` | 必須 | なし | 本文・宛先の雛形とする Gmail 下書きのラベル名 |
    | `INVOICE_DATE_CELL` | 任意 | `J13` | 請求日を書き込むセル |
    | `DUE_DATE_CELL` | 任意 | `J14` | お支払い期限を書き込むセル |

3. メールの宛先・本文・署名は、`EMAIL_TEMPLATE_LABEL` のラベルを付与した Gmail 下書きから引き継ぐ。
   下書きは検索の先頭1件のみを使用するため、取引先ごとに別のラベルを割り当てる。
4. 新しい取引先の追加は、clasp 設定ファイルの追加とスクリプトプロパティの設定のみで完結し、
   ソースコードの変更を必要としない。

## 4. 非機能要件

- 実行環境: Google Apps Script ランタイム（コンテナバインド型でスプレッドシートに紐付く）。
- 外部依存: なし。標準サービス（Spreadsheet / Drive / Gmail / UrlFetch / Script）のみを利用する。
- 権限スコープ: `@OnlyCurrentDoc` により、スクリプトのアクセス対象を当該スプレッドシートに限定する。
- ログ・通知: 主要処理の進捗および異常を `Logger.log` に記録し、UI が利用可能な場合は
  `SpreadsheetApp.getUi().alert` でダイアログ表示する。異常時は例外を再スローし、
  時間主導型トリガーでの実行時に GAS の失敗通知メールが届くようにする。

## 5. 制約・前提

- スプレッドシートが Google ドライブ上のいずれかのフォルダ配下に置かれていること（マイドライブ直下や親フォルダなしの状態は対象外）。
- 利用者が Gmail / Drive / UrlFetch / Spreadsheet の OAuth スコープに同意済みであること。
- 請求書スプレッドシートのアクティブシートが、そのまま PDF 化したいシートになっていること。

## 6. スコープ外

- 下書きの自動送信。
- 複数シート（請求書＋明細など）を 1 つの PDF にまとめる処理。
- スプレッドシート UI 上での設定値編集（フォーム・サイドバー化）。
- 過去分・将来分など任意年月の指定実行（実行日基準のロジックのみ提供）。
- 取引先ごとに請求書フォーマット（シート名・レイアウト）そのものを切り替える機能。
  差分として吸収するのは日付の書き込み先セルまでとする。
